# 2026년 10월 23일 Day5 학습 기록 

### 1. 머신러닝 기본 개념
- 입력 데이터(x): 정답 예측을 위해 사용하는 데이터
- 정답 데이터(Y): 모델이 학습할 정답 값
- train(학습) / valid(검증) / test(테스트): 학습과 평가를 위해 데이터를 나누는 방법
- 데이터 누수: 평가용 데이터의 정보가 학습 과정에 부적절하게 사용되는 문제

### 2. 데이터 전처리
- SimpleImputer: 결측값을 지정한 기준으로 대체한다.
- StandardScaler: 숫자 데이터의 크기를 표준화 한다.
- OneHotEncoder: 범주형 데이터를 숫자형태로 변환한다.
- ColumnTransformer: 열마다 다른 전처리를 적용한다.

### 3. 학습 과정 연결
- Pipeline: 전처리 과정이나 모델을 하나의 흐름으로 연결한다.
- fit(): 학습 데이터에서 전처리 과정이나 모델을 학습한다.
- transform(): 학습한 기준을 통해 데이터를 변환한다.
- predict(): 학습된 모델로 결과 예측한다.
- DummyClassifier: 간단한 기준 모델을 만들어서 실제 모델과 비교할 출발점으로 활용한다.

### 4.오늘 이해한 점
- 전처리 기준은 학습 데이터에서만 학습하고 검증 데이터에서는 기준을 적용해야 데이터 누수를 방지할 수 있다.
